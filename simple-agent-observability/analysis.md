The Braintrust dashboard shows that each agent invocation follows the pattern: `invoke_agent Strands Agents` , `execute_event_loop_cycle`, `chat` (LLM reasoning), `execute_tool duckduckgo_search`, second `execute_event_loop_cycle` → final `chat`. The first LLM call decides a web search is needed, the tool executes, and the second LLM call synthesizes the results into a final answer.

2. There are 5 metrics: Duration, Total tokens, Prompt tokens, Completion tokens, and Estimated cost. The queries "What is the latest news about AI?" and "What are the current trends in machine learning?" each used 13,777 total tokens, took 6.2 seconds, and cost $0.006. This is because both open-ended trend questions caused the search tool to return similarly large bodies of text as results. In contrast, "Who won the 2024 Nobel Prize in Physics?" only used 5,454 tokens, took 4.6 seconds, and cost $0.003. This is because the search did not return any valid results. It only found information up to the 2010 Nobel Prize in Physics, and therefore had very little content to process.

3. I found that prompt tokens are much higher than completion tokens. This is because every LLM call has to include the system prompt, tool definitions, and search results, all of which account for the high token usage.
